## 목적 및 설명
언리얼엔진의 리플리케이션 기능 학습을 위한 프로젝트입니다.
변수, 함수, 이벤트 리플리케이션을 이용한 2인용 클래이 사격 게임입니다.

---

## 주요 구현

## 1. 변수 리플리케이트
  - C++, 블루프린트를 이용해 서버와 클라이언트 상의 변수를 리플리케이트함
  - 득점 변수가 리플리케이트될 때 함수를 호출시켜 UI에 반영하도록 함

## 2. 이벤트 리플리케이트
  - C++, 블루프린트를 이용해 서버, 클라이언트, 멀티케스트 이벤트를 구현
  - 공격 판정, 점수 획득 판정 등을 이벤트로 구현
